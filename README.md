# Campground

A Jellyfin plugin repository for projects by [AHouseOfBards](https://github.com/AHouseOfBards).
Add one link to your server to install and update them.

## Install

Requires Jellyfin 10.11 or later.

1. In the Jellyfin dashboard, open **Plugins → Repositories** and add:

   ```text
   https://ahouseofbards.github.io/Campground-Jellyfin/manifest.json
   ```

2. Open **Plugins → Catalog** and install a plugin.
3. Restart Jellyfin.

## Plugins

### Bonfire

Profiles for Jellyfin. One account holds several people, each with their own watch
history, library access and parental controls. Works with Jellyfin 10.11 and 12.0.

[Features and documentation](https://github.com/AHouseOfBards/Bonfire-JellyProfiles)

This repository offers stable versions only. Bonfire betas are
[published separately](https://github.com/AHouseOfBards/Bonfire-JellyProfiles#install).
